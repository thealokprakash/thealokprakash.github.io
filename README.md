# Alok Prakash — Academic & Engineering Portfolio

A multi-page GitHub Pages portfolio featuring research interests, publications, projects, professional experience, and technical skills.

## Publish
1. Copy the contents of this folder to the root of `thealokprakash.github.io`.
2. Add your CV PDF as `assets/cv.pdf` (the download button expects this path).
3. GitHub repository → Settings → Pages → deploy from `main` / root.

The site uses static HTML/CSS/JS and Google Fonts. Animations respect reduced-motion preferences.
